RIADHA BRAND KIT
================

The logo has been redrawn as clean vector artwork (SVG) from the original PNG presentation
pages. Every slanted edge shares one angle; the wordmark is set in Sora ExtraBold and
converted to outlines. Always use these files rather than screenshots of the old pages.

Logo/SVG, Logo/PNG  (transparent backgrounds, cropped tight to the artwork)
  riadha-logo-primary-*      Mark + wordmark + tagline. Main logo.
  riadha-logo-horizontal-*   Mark + wordmark | tagline on one line. Headers, footers, banners.
  riadha-logo-stacked-*      Mark above wordmark. Square and narrow spaces.
  riadha-logo-wordmark-*     Wordmark only.
  riadha-icon-*              The r mark on its own.
  Variants:
    full-color            Green mark + navy wordmark, for light backgrounds
    full-color-reversed   Green mark + white wordmark, for dark backgrounds
    mono-navy / mono-black / mono-white / mono-green   Single-colour use
  PNG sizes: primary 3000 px, horizontal 3600 px, stacked 2000 px, wordmark 2400 px, icon 1024 px wide.

App_Icon
  riadha-app-icon-ios-1024             App Store / Xcode. Square, opaque, no rounded corners (iOS masks it).
  riadha-app-icon-dark-variant-1024    Optional dark appearance icon.
  riadha-app-icon-play-store-512       Google Play listing icon.
  riadha-app-icon-android-adaptive-*   Adaptive icon layers (108 dp canvas, mark inside the 66 dp safe zone).

Splash_Screens
  Portrait 1080 x 1920 and landscape 1920 x 1080.

Guidelines
  Brand colors (HEX / RGB / CMYK and contrast), typography, clear space and minimum size,
  light and dark mode, footer lockup, brand pattern, and a seamless pattern tile.

Mockups
  The photographic presentations from the original pages (hero banner, phone splash,
  fabric emboss), trimmed of their white page margins. These are for presentations only;
  they are low-resolution images, not production artwork.

Brand typeface: Sora (free from Google Fonts). All text in the SVG files is converted to outlines.
